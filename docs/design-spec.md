# Segrr UI モックアップ 仕様まとめ

個人事業主・フリーランス向け書類管理ツール「Segrr」の UI モックアップ。
見積書 → 契約書 → 請求書をデータ再入力なしで引き継ぎ、顧客・案件の進捗まで一元管理する。
主な利用シーンは PC での作成、スマホでの閲覧と簡単な入力。日本の商習慣（消費税・インボイス制度・源泉徴収）に準拠。

- 成果物: `Segrr UI.dc.html`（全14アートボード／デザインキャンバス）
- 共有パーツ: `Nav.dc.html`（サイドナビ）、`Badge.dc.html`（ステータスバッジ）
- 対象外: PDF帳票（A4レイアウト）

## 1. デザイン方針

| 項目 | 内容 |
| --- | --- |
| 参照 | Preline UI（Tailwind ベース）の作法 |
| 基本姿勢 | 装飾より情報密度。毎日開く業務ツールとして密度優先 |
| 面と枠 | 面は white / gray-50 / gray-100、枠は gray-300 (#d1d5db) で明示 |
| アクセント | blue-600 (#2563eb)。彩度はステータス・警告・系列色のみに使用 |
| 系列色 | blue → violet → emerald → sky → gray（内訳グラフ・進捗・タイムラインで共通） |
| ステータス表現 | 薄い -50 の面 ＋ -700 の文字 ＋ -500 のドット |
| 金額 | 等幅（ui-monospace）＋ tabular-nums ＋ 右揃え ＋ 3桁区切り。マイナスは先頭に「-」で赤 |
| 角丸 | コントロール 8px（rounded-lg）／カード・ウインドウ 12px（rounded-xl）／バッジ 999px |
| 主要寸法 | サイドバー 260px、ヘッダー 64px、ボタン 38px、入力 42px、表の行 48px / ヘッダ 40px |
| テーマ | ライトを主、ダークも定義（トークンは両方併記、画面はダッシュボードで提示） |

## 3. 必ず設計した状態

### ステータスバッジ
- 見積書: 下書き / 送付済 / 承認済 / 却下
- 契約書: 下書き / 送付済 / 締結済 / キャンセル
- 請求書: 下書き / 送付済 / 入金済 / キャンセル

### 日付から算出する状態の重ね方
- ステータスは置き換えず、算出値を枠線バッジで**重ねて**表示（例: 送付済 ＋ 期限切れ）
- 期限3日前から「あと2日」の警告バッジ
- 承認済の見積は有効期限切れでも警告色にしない（実害なし）
- 入金済・キャンセルには期限バッジを出さない

### 編集ロック
- 契約に変換済みの見積、請求発行済みの契約は編集不可
- グレーアウトだけにせず、**理由**（契約 CTR-0031 に変換済み）と**代替手段**（複製して新規作成／変更契約を作成）を必ず併記
- ロック中の項目は面 gray-100、文字 gray-600、枠は通常より1段薄く

### 金額超過エラー
- 契約残額を超えた入力で枠線・文字を赤、超過額を明示（「残額 ¥400,000 を ¥100,000 超えています」）
- 修正導線（残額にする／変更契約を作成）を併置し、送付ボタンはエラー解消まで無効

### 空状態
- 顧客ゼロ / 案件ゼロ / 書類ゼロ（絞り込み結果ゼロ）の3種
- 明細0行のフォーム

## 4. 金額サマリ（適格請求書の要件）

見積・請求の下部に税率別の内訳をすべて表示する。

```
10%対象   小計 ¥1,000   消費税 ¥100
8%対象    小計 ¥999     消費税 ¥79
税抜合計 ¥1,999 / 消費税合計 ¥179 / 合計(税込) ¥2,178
```

### 源泉徴収（請求作成）

```
合計(税込)      ¥1,100,000
源泉徴収        -¥102,100      （税抜額 × 10.21%）
差引請求額       ¥997,900
```

- 源泉徴収は請求単位で ON/OFF（顧客ごとの既定値を設定で上書き可能）
- 支払金額が100万円を超える場合の段階計算（超過分 20.42%）は現時点で未対応。設定で税率の上書きを想定

## 5. 共通パーツ

- サイドナビ（260px・アイコン＋件数バッジ、アクティブは gray-100 ＋ blue アイコン）
- ボタン: 主（blue-600 塗り）／副（白＋gray-300 枠）／テキスト／危険（red 枠）／無効
- テキスト入力・セレクト・日付入力（42px、フォーカスは blue リング、ロックは gray 面）
- テーブル（uppercase の text-xs ヘッダー、48px 行、期限切れ行は薄い赤で着色）
- ステータスバッジ、金額サマリ、ダイアログ、通知（成功／失敗）、エラーメッセージ
- スマホ幅のナビ: 主要4つをタブバーに常設（44px 以上）、残りはドロワー／設定内

---

## 6. 前提（要確認）

- 通貨は円のみ
- 1案件に契約は1通
- 見積は契約変換後にロック、契約は請求発行後にロック（いずれも複製／変更契約で新規作成へ誘導）
- 源泉徴収は税抜額に 10.21%（100万円超の段階計算は未対応）
- 税計算は税抜入力・明細単位で端数切捨（設定で変更可能）
