あなたは査読役です。以下の差分をレビューしてください。

## レビュー対象

$ARGUMENTS

対象の指定がなければ `git diff HEAD` の差分を見てください。
**リポジトリ全体は読まないでください。** 差分と、そこから直接参照されているファイルだけに絞ります。

## 特に見てほしい点

- 金額・消費税・源泉徴収の計算が `docs/db-constraints.sql` のトリガーと一致しているか
  (TS側の計算はUIプレビュー専用で、DBが正)
- サービス層がトリガー算出カラム(合計・消費税・源泉徴収)を書き込んでいないか
- `organizationId` をリクエストボディから受け取っていないか(必ずセッション由来)
- 見積→契約→請求の変換で、明細が参照ではなくコピーされているか
- 分割請求の超過チェックが税抜で行われているか

## 出力の形式

指摘を **深刻度 × 確信度** でランク付けし、上位から並べてください。1件ずつ次を書きます。

1. ファイルと行
2. 何が問題か(1〜2文)
3. どう壊れるか(具体的な入力と結果)
4. 提案する修正

## 守ること

- **パッチを当てないでください。** 指摘までが役割で、適用はPMの承認後に実装側が行います
- 上位7件までに絞ってください
