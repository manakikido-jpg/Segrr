# 同梱フォント

`NotoSansJP-Regular.otf` / `NotoSansJP-Bold.otf`

- 書体: Noto Sans Japanese
- 配布元: https://github.com/notofonts/noto-cjk
- ライセンス: SIL Open Font License 1.1 (https://openfontlicense.org/)

PDF帳票に埋め込むために同梱しています。**システムフォントに頼らないこと。**
指定しないと Chromium が別のCJKフォント(中国語など)へフォールバックし、
日本語として誤った字形(直・骨・化・葛 など)で印字されます。
サーバー環境によっては日本語フォントが一切なく、豆腐になります。
